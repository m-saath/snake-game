# Snake Game

This is a simple Snake game built using HTML, CSS, and JavaScript. The game is played within a web browser and features basic controls to move the snake around the canvas to eat food and grow in size.

## Features
- Classic Snake game mechanics
- Responsive controls using both arrow keys and `W`, `A`, `S`, `D` keys
- Score display to track your progress
- Modern and visually appealing design
